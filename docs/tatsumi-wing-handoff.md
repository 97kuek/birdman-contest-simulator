# 竜海の左右の翼持ちはいつ手を離したか

**離台は引き続き機上時刻3.90秒を基準にする。** 本番映像では、左翼の手元と翼の間に湖面がはっきり見えるのは動画123.423秒、右翼で同じ判断ができるのは123.457秒だった。左右はパイロットから見た向きで、後方カメラでも画面の左右と一致する。二つの時刻は映像上で分離を確認できる上限の目安。指先や支持力までは見えず、左が先に手を離したと決めるだけの差はない。[鳥科が掲載した大会映像](https://torica-tus.com/2025/11/14/2025/)・[本番の該当場面](https://www.youtube.com/watch?v=brdhsnknoKs&t=122s)

## 左右を別々にコマ送りした結果

1920×1080の公式プレーヤーで、121.221〜123.991秒の連続84コマを読んだ。実際に表示されたフレームの時刻（`requestVideoFrameCallback` の `mediaTime`）を用いた。隣接コマの間隔は約0.03337秒。手元が翼下縁に重なる、境界がにじむ、間に湖面が見えて以後も広がる、の順に確認した。頭や肩が翼の下を通り過ぎた時刻、尾部の中央補助者の動きは手放しの判定から除いた。

| 翼持ち | 重なり・判別が難しいコマ（動画秒） | 分離が明瞭なコマ | 見え方 |
|---|---|---|---|
| 左翼 | 123.357で赤い手元の輪郭が翼下縁に重なる。123.390でも境界がにじむ。 | **123.423** | 赤い輪郭と翼の間に湖面の帯が見え、次のコマで広がる。 |
| 右翼 | 123.390では明るい手元と翼下縁が近接。123.423では細い暗部が見えるが、圧縮像と区別しにくい。 | **123.457** | 湖面が続いて見え、手元が翼から遠ざかる。 |

左翼で明瞭な重なりから分離まで約0.067秒、右翼で近接から明瞭な分離まで約0.067秒。これは**輪郭の読み取り区間**で、実際の接触を挟む保証のある区間ではない。奥行き方向に離れても輪郭は重なる。右翼は特に、手首や指を連続して指し示せない。両者の明瞭な分離は1コマ違うが、手放しの順序と荷重がゼロになった瞬間は判別できない。

同じ動画の289.823〜291.091秒のリプレイ39コマも確認した。本番123.390／123.423／123.457秒と、リプレイ290.223／290.257／290.290秒では、両翼、手元、台端の位置関係が一致する。同じ後方映像の再使用なので、別方向から接触を判定する根拠は増えない。手元を再確認する場合は、本番を1080pで2分03秒付近に一時停止し、PCのYouTubeプレーヤーで「.」を押して1コマずつ進める。両手元は、元画像の左上を原点におおむね左 (900, 585)、右 (1180, 605) 付近にある。[大会リプレイ](https://www.youtube.com/watch?v=brdhsnknoKs&t=289s)

## 同じ飛行で超音波計と両IMUが示すもの

下向きの超音波計は機上3.757秒で1.22 m、3.813秒で5.05 mへ変わった。その後3.925秒に4.66 m、3.976秒に3.67 m、4.085秒に測距範囲外を表す10 mが出る。台の近くで反射が変わる区間の中に3.90秒が入る。最初の距離の跳び、範囲外への移行とも、翼持ちの左右の手には対応づけられない。[機上生ログ](https://github.com/torica-org/25th_Analysis/blob/115723c24ce9e64c07c79215770acc7559518d42/getWindVector/src/2025FlightLog.csv)・[超音波計の出力仕様と離台の検証](release-imu.md)

各候補時刻の前後0.20秒の収録値に直線を当てた。ピッチの符号は機首上げを正にそろえた。ロールは各IMUの記録角の傾き。値は角度履歴の変化率（°/s）で、手に掛かった力を測るものではない。

| 機上時刻 (s) | ピッチ変化率　主／空力計側 | ロール変化率　主／空力計側 |
|---:|---:|---:|
| 3.85 | −12.72／−12.76 | +1.67／+1.91 |
| **3.90** | **−14.41／−15.07** | **+2.09／+1.88** |
| 3.95 | −14.96／−14.97 | +2.08／+1.83 |
| 3.98 | −15.83／−15.30 | +2.09／+1.84 |

3.90秒では両IMUとも機首下げ中で、モデルの離台角速度−14°/sと整合する。ロール角には3.869／3.925秒で主IMU 2.50／2.50°、空力計側3.60／3.65°が記録された。約0.056秒離れたこの2標本の間だけでも映像の1コマより長い。符号も手放し順を一意に表さない。左右への反力を別々に測った記録がないため、短い非対称荷重の有無は決められない。[両IMUを同じ機上時刻で照合する解析](../analysis/release-imu.py)

従来の対応は動画123.42秒を機上3.90秒に合わせている。この対応を仮定して足し引きすると、左右の分離が明瞭なコマは機上3.903秒と3.937秒に相当する。この換算値を使って3.90秒を独立に検証することはできない。時計には共通の同期信号がなく、以前の約±0.60秒は映像と機上の対応に見込んだ幅。今回狭まったのは映像内で左右の輪郭を識別できる範囲である。[従来の同期の根拠](tatsumi-video-timing.md)

## 離台後2〜10秒での判断

飛行条件・操縦は固定し、原点候補ごとに実測を集計し直した。0.25秒ごとに前後0.25秒の主IMU・補正気圧高度・ピトー対気速度の中央値を取り、同時刻のモデルとのRMSEを計算した。各欄は **2〜5秒／5〜10秒** の順。[処理済み機上ログ](https://github.com/torica-org/25th_Analysis/blob/115723c24ce9e64c07c79215770acc7559518d42/flightDataPlot/src/2025_Tatsumi.csv)

| 機上原点 (s) | ピッチ (°) | 計器高度 (m) | ピトー速度 (m/s) |
|---:|---:|---:|---:|
| 3.85 | 1.577／0.469 | 0.521／1.097 | 0.198／0.117 |
| **3.90** | **1.520／0.508** | **0.504／1.095** | **0.182／0.115** |
| 3.95 | 1.478／0.570 | 0.480／1.091 | 0.183／0.114 |
| 3.98 | 1.450／0.620 | 0.486／1.090 | 0.191／0.121 |

3.85秒は後半のピッチには合うが2〜5秒の3項目が悪化する。3.98秒は2〜5秒のピッチに合う一方、5〜10秒は0.508°から0.620°へ広がり、速度誤差も両区間で増える。さらに3.98秒で初期姿勢・角速度も同時刻の主IMUから取り直すと、ピッチRMSEは1.811°／0.841°になる。既存モデルを同じ試技で検証した結果で、同期時刻の独立した推定ではない。映像・超音波・両IMUとも3.90秒の設定と矛盾せず、左右別の荷重や時刻を新たに仮定する根拠は得られなかった。[原点別の再計算](../analysis/release-loads.js)・[荷重と尾翼の風の感度試験](tatsumi-release-loads.md)

再計算にはチームの固定版CSVを使う。いずれも読み込み時にGit blobを照合する。

```sh
python3 analysis/release-imu.py path/to/2025FlightLog.csv path/to/2025_Tatsumi.csv
node analysis/release-loads.js path/to/2025_Tatsumi.csv --offsets-csv
```

同じ離台時刻で左右の手放しを1コマずらした場合のバンク角と、離台後10秒間の両IMUとの比較を掲載した。[手放し順とロールの感度試験](tatsumi-wing-handoff-roll.md)
