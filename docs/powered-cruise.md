# 聯とSkyronの60秒巡航試験

「資料・出典」から[巡航試験](../cruise.html)を開く。最初の30秒は設計出力、残り30秒は設計出力の0・75・100・125%を選べる。機首の姿勢を固定し、水平速度・鉛直速度・プロペラ回転を積分する。高度は初期位置からの差で、水面や発進台との接触を含まない。

| 設計値 | 東北大学 Windnauts「聯」2023 | 早稲田大学 WASA「Skyron」2026 |
| --- | ---: | ---: |
| 全備質量 / 翼幅 / 翼面積 | 87.7 kg / 32.2 m / 28.25 m² | 100.6 kg / 34 m / 29.01 m² |
| 設計機速 / 必要出力（Skyronはパイロット出力） | 7.20 m/s / 203 W | 7.4 m/s / 216 W |
| プロペラ半径 / 回転数 / 推力 | 1.55 m / 144 rpm / 22.0 N | 1.50 m / 135 rpm / 24.0 N |
| 設計推力 × 機速 | 158.4 W | 177.6 W |

聯の出典は[チームの技術報告 p.21](https://www.ifs.tohoku.ac.jp/~Boeing/ppt/20231214/5_Windnauts_2022-23.pdf#page=21)。Skyronの出典は提供の第48回三面図（2026年2月13日）の機体・主翼・プロペラ諸元。Skyronのプロペラ効率欄は0.89。推進仕事率とパイロット出力の比は約0.82で、プロペラ単体と駆動系全体では効率の定義が異なる。構造図1/3でねじりチェーン、プーリー、プロペラ側フリーギア、2/3でフライングワイヤーと尾翼のリンク、3/3でプロペラ回転計・対気速度計・舵の信号経路を確認できる。今後Skyronを3D化するときの根拠になる。構造図3/3の250 mはチームの警報距離である。

## 数値試験で確認できたこと

巡航設計点で揚力が重量、推力が抵抗と釣り合うように係数を合わせた。無風で姿勢と出力を変えずに60秒積分すると、聯は432.0 m、Skyronは444.0 m進み、高度変化はどちらも0.001 m未満だった。これは力の符号・単位・積分の整合を調べる試験である。30秒で漕ぐのをやめると、聯の回転はすぐには止まらず、60秒時点の速度は6.70 m/s、高度は開始時より4.62 m低くなった。この応答の独立検証には、漕ぎ止めを含む回転数・対気速度・高度の同期記録が要る。

揚力曲線と誘導抗力は有限翼近似とし、空気密度1.225 kg/m³、翼効率0.85、最大揚力係数1.45を仮定した。固定した姿勢で飛行経路が下向きになると迎角が増える。理想円板の推力は誘導速度から求め、巡航点で必要な円板仕事率を合わせた。回転負荷トルクは回転数の2乗に比例すると仮定し、入力側を含む有効慣性0.8 kg m²で駆動の遅れを表す。伝達損失はまとめて扱う。翼のたわみ、地面効果、ピッチ自由度、プロペラ停止時の風車抵抗はこの試験の対象外。とくに漕ぎ止め後の回転減衰は慣性と負荷曲線に依存する。[計算コード](../src/domain/powered-cruise.js)・[再現テスト](../tests/powered-cruise.test.js)

## 2026年コースに適用する条件

提供の第48回ルールブック A-1〜A-6（pp.8–11）を確認した。以下は競技モード実装用の条件で、60秒試験の距離は大会の採点対象外である。[主催者の公開概要](https://www.ytv.co.jp/birdman/about/)

- プラットホーム標準値は高さ10 m、助走路10 m、傾斜3.5°。発進時の機体保持者は最大3名。
- 南北の往復はどちらからでも開始できる。各ポイントのパイロンを回り、他方のルートへ移るときはプラットホームパイロンを回る。開始地点から各ポイントは10.975 km、各ポイントからプラットホームパイロンは10.1225 km。
- 両ルートの往復後、設定された着水ゾーン（湖側半径300 mの円周内）に到達し、禁止区域を除く湖上へ着水すると42.195 kmの完全飛行。同距離なら到達時間が短いチームが上位。単純なGPS累積距離だけでは判定できない。
- 陸地や島のほか、指定の水域も飛行禁止。湖岸から350 m以内の水域には実行委員会指定のプラットホーム周辺の例外がある。上限高度は水面から10 m。区域の種類、回避行動、実行委員会の指示により罰則が異なる。コースの正確な境界座標は別途必要。
- 聯が飛んだ2023年はコース長・条件が異なる。[2023年大会の航路](https://www.ifs.tohoku.ac.jp/~Boeing/ppt/20231214/5_Windnauts_2022-23.pdf#page=16)
