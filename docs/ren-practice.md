# 聯で湖上を飛ぶ

プラットフォームで旗を読んで向きを決め、1・2・3番の順にブイの23 m以内を通過する。通過判定は対地位置で行う。操縦席のGPSはブイと機体の位置を上から見た図で、機影は実際に進んでいる方向を指す。橙色の線が次の目標への直線。ブイは白帯の本数でも見分けられる。全通過の時刻を記録し、その後も着水まで飛べる。練習コースと所要時間はゲーム独自の設定である。

通常操作に追加したのは漕ぐペースの選択だけ。PCでは1・2・3、スマホでは同じ3ボタン。巡航は203 W、強めは300 W。手元の「加速余力」は、持続できる出力（クリティカルパワー、CP）を超えて行える仕事量 W′ の残り。標準ライダーを CP 210 W、W′ 15 kJ と仮定した。3分全力試験では終盤の出力が個人の CP に近づき、別測定した W′ の群平均は16.0 kJだった。聯のパイロット本人の計測値は得られていない。[Vanhatalo ほかの自転車実験](https://pubmed.ncbi.nlm.nih.gov/17473782/)

発進前の予回転から実出力で収支を計算する。終盤は残った仕事量を22秒の時定数で使える範囲に制限する。22秒は出力が滑らかに下がるように選んだモデル値。標準条件で満量から300 Wを要求し続ける計算では、120秒後300 W、180秒後229 W、240秒後211 W。手元の出力とペダルの音には実出力を使う。加速余力0%付近でも有酸素運動で出せる分は残る。

回復は残量の不足分と回復時の出力で計算する。CPとの出力差 D に対し時定数を 546 exp(−0.01 D) + 316 秒と置き、CPに近い40 W幅では回復速度を滑らかに絞る。標準条件で空の状態から1分休脚すると約15%、150 Wなら約9%、203 Wなら約1%戻る。血中乳酸濃度をゲーム内の疲労値に直接換算していない。[Skiba ほかの間欠運動実験](https://pubmed.ncbi.nlm.nih.gov/22382171/)・[回復負荷と回復時間の検証](https://pubmed.ncbi.nlm.nih.gov/32555021/)

昼は30±2℃、夜は23±2℃を中心とした仮想気象で、飛行ごとの風の種から気温と湿度を決める。暑さ・湿度・フェアリングに入る相対風でCPを補正する。静止空気と送風を比較した研究を参考に、送風の効果には上限を設けた。換気率40%と気温補正はゲーム用の推定で、大会当日の観測や人体の深部温度・乳酸の実測値を表すものではない。[暑熱下の気流と出力の実験](https://pubmed.ncbi.nlm.nih.gov/36989528/)

巡航中は追加のメーターを画面に重ねず、速度、高さ、進路、実出力と余力を操縦席の縦型端末に集約した。伴走艇が180 m以内なら、次のブイへの修正方向、横流れ、ペースの助言を字幕で伝える。飛行禁止区域の警告が優先される。端末の形状、配線と取り付けは電装写真を参考にした。翼紐の取り付け位置・長さ、補助員が回収する動作は推定造形。紐の張力による翼変形は未計算。[Windnauts電装写真 p.9](https://www.ifs.tohoku.ac.jp/~Boeing/ppt/20231214/5_Windnauts_2022-23.pdf#page=9)
