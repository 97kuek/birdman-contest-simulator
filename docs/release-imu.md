# 竜海の離台時の姿勢と機首下げ速度

2025年大会の離台を機上ログの3.90秒に置くと、主IMUから推定したピッチは **−0.19°、変化率は−14.41°/s** だった。機首上げを正とする。モデルの初期条件（0°、−14°/s）は、この同期での実測と合う。実機では離台後0.50秒でも−13.91°/sで機首が下がり、1.00秒で−4.24°/sまで緩む。最初の機首下げの深さを検証するには、離台の一瞬に加え、この間に角速度がどう変わるかを照合する必要がある。[大会のセンサーログ](https://github.com/torica-org/25th_Analysis/blob/115723c24ce9e64c07c79215770acc7559518d42/getWindVector/src/2025FlightLog.csv)・[竜海の初期条件](../src/domain/launch.js)

## 二つのIMUが示す角度と角速度

チームの処理済みCSVの `Time` と `Pitch` は、全1,043行で生CSVの `FlightTime` と `bno_pitch` に一致する。これを既存の比較と同じく符号反転して主IMUのピッチとし、空力計側には生の `data_air_bno_pitch` を使った。各センサーの角度に、実際の記録時刻を使って前後0.20秒の最小二乗直線を当て、中心時刻の角度と傾きを求めた。傾きはオイラー角の時間変化率で、ジャイロで直接測った機体軸まわりの角速度とは区別する。基準操縦の縦運動ではモデルの両者は一致する。[チームの処理済みCSV](https://github.com/torica-org/25th_Analysis/blob/115723c24ce9e64c07c79215770acc7559518d42/flightDataPlot/src/2025_Tatsumi.csv)・[モデルの姿勢微分](../src/domain/aircraft-dynamics.js)

離台後10秒の174標本では、空力計側は主IMUより中央値で1.36°機首下げ側を示す。両角度の水準差の中央値を引いた後のRMS差は、同じ行を照合した場合に0.196°。同じ主IMU標本に対して空力計側を1行前後にずらすと0.388°と0.360°になった。中央値の記録間隔は約58 ms。2系統で機首下げの経過を確認できるが、共通の遅延や絶対的な取付角のずれは、この照合からは決まらない。[再計算コード](../analysis/release-imu.py)

変更前の基準操縦（`dd499b8`）では、離台後0.25秒の変化率は−15.43°/sで、主IMUの−14.62°/sに近い。0.50秒では計算−9.85°/s・実測−13.91°/s、0.75秒では計算−4.95°/s・実測−11.56°/sとなり、モデルの機首下げが早く緩んでいる。この比較では基準風・標準設計・弾性翼で `simulateFlight` を実行し、`poseAt` の姿勢を各ログ行の時刻（`FlightTime − 3.90`）に補間して、主IMUと同じ前後0.20秒の直線を当てた。既定の体重移動は0.40秒から後方へ向かう。時刻の重なりだけでは、この操作に誤差の全量を帰せない。[変更前の基準操縦](elastic-pullup.md)・[飛行と記録時刻の補間](../src/domain/flight.js)

## 離台時刻と窓幅でどれだけ変わるか

機体下の超音波測距はログ3.757秒に1.22 m、3.813秒に5.05 m、3.976秒に3.67 m、4.085秒に10 mを示した。計器の下を台端が通る時刻と、最後の補助員の手が離れる時刻は別の事象である。表の3.70〜4.10秒の各行は、同期を±0.20秒動かした場合に一緒に変わる角度・角速度の候補として使える。同期を変える試算では、その条件での観測経過時刻も同時に変更する。[従来の離台推定](flight-validation.md)

離台を3.90秒に固定して対称窓の半幅を0.15、0.20、0.25、0.30秒に変えると、主IMUの傾きは順に−13.52、−14.41、−14.17、−13.85°/sになる。一方、3.65〜3.90秒だけで求めた傾きは−10.26°/s（4標本）、3.90〜4.15秒だけでは−18.06°/s（5標本）。空力計側も順に−10.23、−17.08°/sである。後半の値は直後の機首下げが強まる区間を含む。−17〜−18°/sは片側窓に基づく感度試験に使えるが、手が離れた瞬間の角速度をその精度で測定したわけではない。この幅は同期と推定法による差で、統計的な信頼区間ではない。[再計算コード](../analysis/release-imu.py)

離台後2秒間の主IMU生値の最小は1.193秒の−13.31°。既存の0.25秒刻み・前後0.25秒の中央値では1.25秒の−12.75°になる。計算側も同じ時刻と集計法で比較すれば、窓による見かけの差を避けられる。身体位置と補助員の反力は両CSVに収録されていない。角度履歴から機首下げの継続時間は調べられるが、適合した体重移動量や操作時刻を実機の操縦履歴と同定するには別の記録が要る。[既存のピッチ・高度・速度の比較値](../src/domain/pullup-data.js)・[体重移動を変えた試算](elastic-pullup.md)

## 速度ベクトルは台面に沿っていたか

姿勢を保ったまま沈むこともできるため、IMUのピッチから速度ベクトルの傾き（経路角）は決まらない。機体重心が対地8 m/sで進むモデルでは、経路角−7°の鉛直速度は−0.97 m/s、正面発進の台面に沿う−3.5°なら−0.49 m/sとなる。機上ログ3.90秒を中心に高度を時刻に直線回帰した結果を示す。チーム補正高度はこの区間で生CSVの `true_alt` と一致する。[速度ベクトルの初期化](../src/domain/aircraft-dynamics.js)・[チームの処理済み高度](https://github.com/torica-org/25th_Analysis/blob/115723c24ce9e64c07c79215770acc7559518d42/flightDataPlot/src/2025_Tatsumi.csv)

前後0.50秒のチーム補正高度は−7°での計算に近いが、窓を狭めると傾きの符号まで変わる。空力計側の気圧高度はどの窓でも下降を示した。機上推定高度 `estimated_altitude_lake_m` はログ3.757秒から3.813秒の間に−1.24 mから10.51 mへ跳んでおり、この窓の傾きを飛行の鉛直速度には使えない。気圧計の取付位置は機体の回転でも上下し、ピトー系は対気速度を測る。各窓は離台後に鉛直速度が変化する区間も含む。−7°は1秒間の傾向と整合し、−3.5°は台面に沿った助走速度を連続に引き継ぐ比較条件となる。どちらかを離台瞬間の実測経路角として選ぶだけの情報は得られない。[高度・速度の計測方法](pullup-validation.md)・[再計算コード](../analysis/release-imu.py)
