# 聯の片翼突風と逆ラダー

7.20 m/s、翼代表点高度13.12 m、196.63 Wの水平飛行から、左翼に1秒間、最大0.5 m/sの上昇風を与えた。1秒時点の全状態をコピーして各実験に分岐し、以降の風をゼロにした。正のバンクは右傾。下記の「前」は尾翼の局所風導入後・翼の接線修正前を指す。

## 傾きが増えた理由

| 突風が終わった後に外した作用 | 10秒時点のバンク（前 → 修正後） |
| --- | ---: |
| 全作用あり | 右2.17° → 右1.37° |
| 垂直尾翼の力とそのモーメント | 左0.98° → 左0.70° |
| 翼の横方向の気流が上反角を介して迎角を変える作用 | 右6.10° → 右6.07° |
| ヨー角速度による左右翼の前後速度差 | 右0.37° → 右0.24° |

右に傾いた機体に生じた横滑りで垂直尾翼が左に押され、機首が右を向く。旋回外側の左翼が速くなり、揚力差が右傾を深める。一方、上反角を介した横滑りの作用はこの条件では復元側に働く。修正後の5秒時点ではヨー角速度は右0.97°/s、尾翼の横力は左4.90 N、左翼の前後速度は右翼より0.232 m/s大きく、揚力は1.33 N大きかった。各行は相互作用を含む別々の軌跡であり、差を足して寄与率にすることはできない。

3Dの主翼は外側ほど上に曲がる。従来は翼根と代表点を結ぶ直線を断面の向きに使っていた。代表点での接線から空気力の向きを取るように修正した。1秒後の右傾は1.07°から1.05°、10秒後は2.17°から1.37°。尾翼効率と機体の慣性は据え置いた。

## 突風直後に左ラダーを入れる

1秒時点から下表の入力を与えて手を離す。水平通過までの時間と高度差の基準は入力開始。最大の左傾と最後の高度は突風開始後10秒までを集計した。

| 左ラダー | 最初の水平通過 | 最大の左傾 | 10秒時のバンク | 入力開始からの高度差 |
| --- | ---: | ---: | ---: | ---: |
| 中立 | 通過せず | 0° | 右1.37° | −3.3 cm |

| 50%・1秒 | 1.42秒後 | 0.07° | 右0.22° | −1.8 cm |
| 全舵・0.5秒 | 1.05秒後 | 0.09° | 右0.20° | −2.6 cm |
| 全舵・1秒 | 0.82秒後 | 1.15° | 左0.93° | −4.0 cm |

## 角田試験飛行との照合

2023年7月2日の11本目の後方映像を2:48から2:58まで毎秒計測した。山並みの特徴点を2:48と各フレームで対応付け、カメラの回転変化を差し引いた。後方から見て翼根の左右等距離の複数地点を結び、見かけの翼の傾きを取った。2:48を基準に、2:50で右へ1.82°、2:52で右へ2.13°、2:54で右へ0.96°、2:56で左へ0.19°。2:48–2:52の平均変化は右0.53°/s、続く4秒は左0.58°/s。翼根の採り方と比較箇所を変えたとき、2:52の変化は右2.05〜2.26°だった。[後方映像 2:48から](https://www.youtube.com/watch?v=bPxCafDaOt0&t=168s)・[チームの試験一覧 pp.14–15](https://www.ifs.tohoku.ac.jp/~Boeing/ppt/20231214/5_Windnauts_2022-23.pdf#page=14)

実機映像では数秒かけて傾きが増え、その後戻る。無操舵の計算では10秒後も右傾が残り、短い逆舵を入れると向きが変わった。映像には同期舵角・風速・IMUがなく、左右のたわみと遠近も翼の見え方に影響する。この測定で実機の絶対バンク、逆舵の有無や突風の強さは特定できない。
