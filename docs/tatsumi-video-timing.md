# 竜海の大会映像に離台後の時刻をつける

鳥科が機体ページに掲載した第47回大会の公式映像を使った。映像上の離台の目安は **2分03.42秒**、IMU側は機上時刻 **3.90秒** とした。離台後0.5〜1.25秒は、この合わせ方で動画2分03.92〜04.67秒に当たる。後上方の映像ではパイロットとポッドが重なり、肩や腰が胴体に対して動き始める時刻は読み取れない。[2025年機と映像の出典（鳥科）](https://torica-tus.com/2025/11/14/2025/)・[公式動画の助走から見る](https://www.youtube.com/watch?v=brdhsnknoKs&t=122s)

## どの瞬間を合わせたか

公式プレーヤーで1080pを選び、本番の映像を停止・シークした。指定したシーク先と、実際に表示されたフレームの時刻には最大1コマ程度の差がある。表にはブラウザの `requestVideoFrameCallback` が返した `mediaTime` を使った。基準の前後では約0.10秒間隔でフレームを確認した。比較画面の「離台後」は動画の表示時刻から123.42秒を引いた値になる。

| 動画時刻（秒） | 離台後の目安 | 見えたもの |
|---:|---:|---|
| 123.023 | −0.40秒 | 両翼の下に翼持ち、尾端の後ろに中央の補助者。三人と機体の輪郭が重なる。 |
| 123.223〜123.523 | −0.20〜+0.10秒 | 左右の翼持ちが台端で身を伏せる。中央の補助者と尾部は後上方カメラから見て重なり続ける。 |
| 123.824 | +0.40秒 | 機体は台の外。尾端と中央の補助者の間にも背景の湖面が見える。 |
| 123.924〜124.725 | +0.50〜+1.30秒 | 後上方から主翼、尾翼、ポッドが遠ざかる。身体の前後位置を示す目印は隠れる。 |
| 124.791〜124.858 | +1.37〜+1.44秒 | 後上方から側方の遠景に切り替わる。 |
| 125.492〜126.493 | +2.07〜+3.07秒 | 機体側面で、胴体後部のブームが画面に対して水平に近づく。 |

123.02〜123.82秒は、補助者と機体の重なりから選んだ**視覚上の同期候補区間**。その中点を表示の原点に採った。最後の手の接触を画素で判定することはできず、映像と機上ログに共通の時刻信号もない。映像側の読み取り幅を約±0.40秒、台端の通過と機上ログの対応幅を約±0.20秒と見積もると、二つの時計の比較には約±0.60秒の幅をみる必要がある。これは二つの幅を足した目安で、統計的信頼区間ではない。カメラ切替時の放送遅延は別途測れていない。[超音波・両IMUの原点と時間窓](release-imu.md)・[公開センサーログ](https://github.com/torica-org/25th_Analysis/blob/115723c24ce9e64c07c79215770acc7559518d42/getWindVector/src/2025FlightLog.csv)

同じ番組内のリプレイも287〜295秒を1秒おきに確認した。287.99秒には助走中のパイロットを近くから捉えたカットがある。288.99秒にはすでにプラットフォーム後方の画角へ切り替わり、離台時は本番と同じ方向から映る。離台後まで続く身体の近景は、このリプレイでも得られない。[インタビュー中のリプレイ](https://www.youtube.com/watch?v=brdhsnknoKs&t=287s)

## 側面の映像から独立に確かめられる動き

側方カメラに切り替わった後は、尾翼の付け根とポッドの間の細いブームを追える。下表は1920×1080画素のフレームでブームの直線部分を測ったもの。座標は左上が原点で、画像右の機首が下がる方向を負とした。[側面カメラの区間](https://www.youtube.com/watch?v=brdhsnknoKs&t=125s)

| 動画秒 | 離台後 | 読み取り両端の画素座標（x, y） | 画面水平への傾き |
|---:|---:|---|---:|
| 124.858 | 1.44秒 | (1244, 435) → (1311, 452) | 約−14° |
| 125.492 | 2.07秒 | (1341, 485) → (1405, 500) | 約−13° |
| 125.993 | 2.57秒 | (1398, 521) → (1460, 528) | 約−7° |
| 126.493 | 3.07秒 | (1446, 538) → (1479, 539) | 約−2° |

各区間でブームの明るい縁を目視で選び、その周囲±3画素から各列で最も明るい画素を採り、行座標を列座標に直線回帰した。追跡範囲は約33〜67画素で、両端の高さの差が2画素動くだけで角度に約2〜3°の差が出る。撮影方向、カメラの水平、機体軸に対するブームの角度も不明である。この系列から使えるのは、機首下げの向きから水平付近に戻る傾向までである。姿勢の角度・変化率をモデルと比較する際はIMUを使う。

側方へ移った後も翼・カウルが肩と腰に重なる。125.49秒のフレームでは機体の投影全長が約220画素で、三面図の全長5.56 mを使うと、胴体に沿う10 cmの移動は概算4画素に相当する。映像には身体の同じ部位を連続して指せる特徴点が見えないため、体重移動の線は計算上の推定として読む。[機体の寸法](https://torica-tus.com/2025/11/14/2025/)

## 映像と時系列を同時に見る

[離台後3秒の比較画面](https://97kuek.github.io/birdman-contest-simulator/opening.html)で時刻を選ぶと、大会映像、主IMUのピッチ、ピッチ変化率、モデルの身体位置を同じ離台後時刻で見られる。再生中は公式プレーヤーの再生時刻にグラフが追従する。比較試算で「身体を離台位置に保持」を選ぶと、他の発進条件を揃えたまま前寄りの姿勢を3秒間維持した場合が破線に出る。「調整前の基準操縦」は `4c0464e` の身体移動条件を使う。[操縦条件ごとの数値](tatsumi-opening-window.md)

ピッチは処理済みCSVの主IMU各標本で機首上げを正にした値。点の間を線形補間して表示する。変化率の推定には、各標本の前後0.20秒に含まれる実際の収録時刻を使う。モデルも同じ各時刻で補間してから傾きを求めた。窓に離台前が入る区間はモデル変化率を空欄にしている。身体位置は重心移動量と区別し、モデルの身体基準点の前後変位をcmで示した。

比較用のデータは、固定版のチームCSVとゲームの飛行計算から次のコマンドで再生成できる。公式映像はYouTubeのプレーヤーで再生する。[処理済みCSV](https://github.com/torica-org/25th_Analysis/blob/115723c24ce9e64c07c79215770acc7559518d42/flightDataPlot/src/2025_Tatsumi.csv)・[表示データの生成](../analysis/export-opening-comparison.js)

```sh
node analysis/export-opening-comparison.js path/to/2025_Tatsumi.csv
```
